## About This Repository

Welcome to my Python programming repository!

This repository documents my journey of learning Python through practical implementation and consistent problem-solving.

It contains programs and exercises covering core Python concepts, starting with basic syntax and gradually moving towards functions, string manipulation, exception handling, file operations, and logical problem-solving.

My objective is to strengthen my programming fundamentals by writing code, experimenting with different approaches, and understanding how programs work.

**My learning approach:** Understand the concept → Write the code → Test the logic → Improve the solution.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/priyanshukanojia5/python.git
```

### 2. Open the project directory

```bash
cd python
```

### 3. Verify Python installation

```bash
python --version
```

### 4. Run a Python program

```bash
python start/first.py
```

You can run any other Python file by specifying its relative path.
